One command. One board. Everyone on your WiFi.

The LAN message board

Run one command and anyone on your WiFi can post messages that show up live on every screen — no accounts, no setup.

$ npx lanyell

Node.js ≥ 18 · works on macOS, Linux and Windows

Features

⚡

Live updates

Server-Sent Events push every new message to all screens instantly — no refresh needed.

📱

Terminal QR code

Others scan the QR in your terminal to open the board on their phone — no typing URLs.

🎨

Per-device colors

Each device gets a stable light tint, so you can tell senders apart at a glance.

✂️

Fold long messages

Long messages clip at a fixed height with a per-item expand/collapse toggle.

🗑️

Anyone can delete

Remove any message; the change syncs to every screen instantly.

📐

Responsive & zero-deps client

One plain HTML file, no build step, stacks cleanly on phone-width screens.

Quick start

Run it Node.js ≥ 18. Pick another port with npx lanyell --port 8080.
Share it Others scan the terminal QR code, or open http://<your-LAN-IP>:3000.
Post away Messages appear live on every screen. If others can't reach it, allow Node through your OS firewall.
